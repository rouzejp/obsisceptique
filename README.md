# README — ObsiSceptique

**Coffre Obsidian pour la zététique, le scepticisme scientifique et le fact-checking.**

ObsiSceptique est un système de connaissance structuré autour de la vérification des faits, du repérage des pseudo-sciences, et de la production de contenus sourcés.

## Utilisation

1. Ouvrir le coffre avec [Obsidian](https://obsidian.md)
2. Commencer par déposer des claims dans `02_Revendications/`
3. Utiliser les templates dans `07_Templates/` pour standardiser les fiches
4. Les vérifications abouties atterrissent dans `03_Verifications/`
